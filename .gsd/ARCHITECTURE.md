## Data Flow

1. **User Inquiry & Booking**:
   - User navigates through services or doctor profiles.
   - Clicks "Book Appointment" or "Home Visit".
   - Form submission routes to Formester API endpoint (`https://app.formester.com/forms/OwuroVfFc0m_/submissions`).
   - Confirmation is returned with reCAPTCHA verification.

2. **WhatsApp Order Flow**:
   - Users browse health packages in `health-packages.php` or `about.php`.
   - Clicks "Buy Package" trigger linking to WhatsApp API (`https://wa.me/916360225347?text=...`) with pre-filled package SKU/title.

3. **Doctor Profile Rendering**:
   - `doctor-profile.php` holds structured array for medical specialists.
   - Profile pages load dynamically or via clean wrappers passing `$current_doctor_id`.
